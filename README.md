# Daymark — Event & Milestone Countdown

A modern, responsive, device-local countdown, birthday, career timeline, goal progress, and date calculator web app with full offline PWA support.

🌐 **Live Web App**: [https://onkarpawar1.github.io/CountDown/](https://onkarpawar1.github.io/CountDown/)

## Features

- **Live Countdowns & Up-Counters**: Unlimited event countdowns with live-ticking smart units, days, hours, and minutes.
- **Birthdays & Anniversaries**: Recurring yearly celebrations with accurate milestone and age calculations.
- **Career & Timeline**: Track professional milestones, job durations, and current experiences.
- **Goal Progress**: Visual percentage completion bars for milestones and deadlines.
- **Date Calculators**: Dual-mode date difference calculators and add/subtract duration tools.
- **Year in Days**: Real-time month-by-month visualization of the year's progress.
- **Data Privacy & Portability**: 100% client-side local storage. Full JSON export and import capabilities.
- **PWA Ready**: Works offline with Service Worker caching and installable on iPhone/iPad (Safari Add to Home Screen) and Android/Desktop (Chrome).

## Deployment

Automated deployment to GitHub Pages via GitHub Actions is pre-configured in `.github/workflows/deploy.yml`. Pushes to `main` branch trigger an automatic build and deployment to GitHub Pages.
